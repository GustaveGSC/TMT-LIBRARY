## 本轮新增：★ 发货物料里的材质大类，作为实木/钣金的硬信号

用户在 2026-05 标注中两次指出「这一点可以从发货物料里得出」。`products` 字段是规范化命名：

```
原材料_木器_桦木_书架层板        → 材质大类 = 木器   → 实木问题
原材料_金属件_铁件_顶部层板      → 材质大类 = 金属件 → 钣金问题
原材料_塑胶件_塑料件_塑料挂钩    → 材质大类 = 塑胶件
```

**备注文字判不出材质**（"书架搁板掉漆""灯支架层板有磕碰"从字面看不出是木还是铁），
但物料名里写得很清楚。我已解析好，在 `rule-suggestions.json` 每单的这些字段里：

| 字段 | 含义 |
|---|---|
| `material_categories` | 材质大类列表，如 `["木器"]` |
| `material_parts` | 部位列表，如 `["书架层板"]` |
| `category_hint` | **硬信号推荐的一级分类**（仅木器/金属件时给出），如 `"实木问题"` |
| `category_hint_strength` | `strong` / `weak` / `null` |
| `weak_hints` | 弱信号（塑胶件/定制件/标准件），**仅参考不要当规则** |

### 使用要求

1. **`category_hint_strength == "strong"` 时，优先采用 `category_hint`**，
   优先级高于从备注文字推断材质。
2. 只有木器→实木问题、金属件→钣金问题是硬信号。塑胶件/定制件/标准件判别力
   都不足 60%，**只作参考**。
3. 无材质信息时（约 83%）才回退到按备注文字判部位。

## v4 新增/修正的原因判定规则（必须执行）

### A. 新增词语 → 原因映射

| 备注出现 | 应判 |
|---|---|
| 鼓包 / 凹凸 | 实木瑕疵 |
| 结疤 / 疤结 | 实木结疤 |
| 漆面不均 / 黏糊印记（未提开裂） | 实木瑕疵 |
| 拉线坏 | 气弹簧拉线破损 |
| 安装造成的磕碰 | 安装损坏 |
| 出现「**重新发**」字眼 | **二次售后**（此前已发过一次售后但不对） |
| 电源滋滋响 | 电源异响 |
| 有气味 | 产品异味 |
| 卡簧（摇把位置） | 手摇把失效 |

### B. 功能问题 vs 破损/异响的区分（第四轮错得较多）

| 备注 | 应判 | 不要判 |
|---|---|---|
| 靠背/椅背 **松** | 椅背失效（功能问题） | 椅背破损 |
| 卡扣**异常** | 该部件失效（功能问题） | 椅垫异响 |
| 明确提到"**支架**坏" | 椅背**支架**破损 | 笼统的椅背失效 |
| 明确提到"更换椅背" | 椅背破损 | |

### C. 优先级补充

- **靠背 > 直管**
- **开裂 > 少螺钉**（"木器开裂 + 桌腿安装少一颗螺丝" → 判实木开裂）
- 桌腿升降**一般指桌高升降**，只有倾斜才涉及气弹簧（"桌腿升降异响" ≠ 气弹簧失效）
- 「无法升降」是关键症状，优先于同时出现的生锈等

### D.「缺失」类判定收紧

| 情形 | 应判 |
|---|---|
| 备注明确写"少/没有"某个具体物料 | 该物料**缺失**（**不是**"发错货"） |
| 备注**没有**提到少物料 | **不能**判缺失 |

例：`探索家U收到没挡笔条` → 挡笔条缺失；`领航员S桌垫起泡` → 桌垫瑕疵（不是桌垫缺失）。

### E. 补充忽略情形

- `补寄个气弹簧手柄，客户扔掉了` → **直接忽略**（客户自身原因且非质量问题）

### F. 前几轮已确认、继续执行的

- **实木件的瑕疵/色差/磕碰/开裂/变形 → 实木问题**；只有非实木件（灯罩/塑料件/桌垫/椅套）
  才归外观不良（第四轮此项修好后召回 52%→86.8%）
- 严重性优先、部件归属（旋转托盘→椅垫、电源线→电源、椅套独立）、
  确定映射（脏污/自动灭/磨损/螺钉弯曲/电流声/电线问题）、非产品问题归类
- 「没提到就不能判」保留，但**不要过度弃答**：能定部位不能定现象时给该部位通用「失效」
  + 中低置信，不要留空；一级分类通常可判，不应大量留空
- 「其他」是兜底类，归不进任何类时直接用它 + 低置信
