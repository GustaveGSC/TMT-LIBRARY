## 本轮要修的三处（第三轮倒退的根因都在我给的规则，不是你没执行）

### 修正一：实木件的外观问题归「实木问题」，不是「外观不良」★ 影响最大

第三轮我给的映射表写了「瑕疵/色差/不平整（外观类）→ 外观不良」，**这条过度泛化了**，
直接造成实木问题分类召回从 83.6% 跌到 **52.0%**（98 单里 21 单被判成外观不良、17 单留空）。

人工的真实口径：

| 部位 | 现象 | 应归类 |
|---|---|---|
| **实木件**（桌面板 / 层板 / 侧板 / 隔板 / 中隔板 / 活动板 / 固定板 / 搁手板 / 面板 / 书架板 / 框架木件） | 瑕疵 / 色差 / 磕碰 / 划伤 / 划痕 / 开裂 / 变形 / 翘 / 不平 / 掉漆 | **实木问题** |
| **非实木件**（灯罩 / 灯头 / 塑料件 / 护套 / 桌垫 / 椅套 等） | 瑕疵 / 色差 / 不平整 | 外观不良 |

第三轮误判实例（都应判「实木问题」）：
```
领航Z120桌面拼接色差大        → 人工 实木色差     你判了 外观不良
探索家U层板瑕疵               → 人工 实木瑕疵     你判了 外观不良
领航员PRO1.2米 桌面有磕碰     → 人工 实木磕碰划伤  你判了 外观不良
领航员Z活动板瑕疵             → 人工 实木瑕疵     你判了 外观不良
```

**判断顺序**：先看部位是不是实木件，再看现象；不要一看到"瑕疵/色差"就归外观不良。
实木问题下的具体原因按现象细分：磕碰划伤 / 色差 / 瑕疵 / 开裂 / 变形 / 尺寸偏差 /
桌面板不平（活动面板翘、不平统一用这个）。

> 第三轮实木问题的**原因层**召回只有 30.6%，与本条同源，修正后应一并改善。

### 修正二：忽略判定——机械部分我已用代码算好，你只做语义部分

第三轮我那条「只写寄什么物料就忽略」是错的，造成精确率 100% → 86.1%（12 单误判）。
用户澄清：只有**纯**「补寄XXX」才忽略；「明睿扭扭断，补寄2个」这种有故障描述的不能忽略。

**已改为代码判定**（`backend/scripts/aftersale/ignore_rule.py`），结果在
`rule-suggestions.json` 的 `rule_ignore` / `rule_ignore_reason` 字段里：

- 含购买/已付/报价类词且无故障描述 → 忽略
- 纯补寄/补发且无故障描述 → 忽略
- 含补寄类词但**有**故障描述 → **不忽略**

实测：2026-06 精确率 96.3%、2026-05（本轮）88.0%，召回约 44–46%。

**你要做的是补召回**：`rule_ignore=false` 的单里，若**备注与留言中找不到任何可推断的
问题、表述含糊**，仍可判「建议忽略」。但——

> **精确率优先。** 前两轮都是零误判（37/37、72/72），第三轮为提召回丢了精确率，
> 是退步不是进步。宁可漏判让人工多筛，不要误判把需处理的单放过去。

### 修正三：「没提到就不能判」保留，但不要过度弃答

这条方向是对的（已预测准确率稳住了），但第三轮执行过头：分类留空 12.6%、
原因与简称留空 20.7%（其中 77 单标了"需人工判断"），导致**总体**准确率反而下降约 10pp
（分类 75.7%→65.8%、原因 64.1%→54.4%、简称 81.3%→71.2%）——在一批原本能判对的单上弃答了。

修正后的执行标准：

| 情形 | 怎么做 |
|---|---|
| 备注完全无法支撑任何现有原因 | 留空 + 需人工判断 |
| **能确定部位、但不确定具体现象** | 给该部位的通用「失效」类 + 中/低置信，**不要留空** |
| 一级分类通常都能判断（比具体原因容易） | **不应留空 12.6%**，尽量给出 |

## 其余规则不变（详见 v3 文档第二节）

- 严重性优先：实木开裂>色差、破损>瑕疵、椅背/椅垫>椅轮、排插烧毁等级最高
- 部件归属：旋转托盘→椅垫、电源线→电源；椅套独立于学习椅；无「升降托盘」
- 确定映射：脏污→产品脏污、自动灭→学习灯不亮、磨损→实木磕碰划伤、
  螺钉弯曲→螺钉破损、电流声→电流异响、电线问题→电线破损
- 非产品问题：客户自身原因→客户原因、发错物料→发错货、重寄后再出问题→二次售后
- 「其他」类连续三轮 0% 召回，已判定为兜底类无稳定特征——**归不进任何类时就用它 + 低置信**，
  不必强行归到具体类（第三轮就是倾向硬归具体类）
