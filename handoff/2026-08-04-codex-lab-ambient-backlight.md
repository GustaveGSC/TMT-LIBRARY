# 模拟手控系统 · 电动桌后置氛围灯重做交接

日期：2026-08-04
状态：本地实现、实际页面截图核验与 Web 生产构建完成，未部署

## 用户要求

氛围灯安装在电动桌后方，作为页面第一层独立模拟；灯带实体需要画出，开启后灯光映射到后方表面形成漫反射。

> 说明：第一版错误理解为“手控器后方背光”，该方案已完全撤销，以下为最终实现。

## 已完成

- 修改 `src/components/lab/AmbientLightStrip.vue`：
  - 绘制木质桌板后沿、黑色灯带轨道、两枚安装卡扣和 48 颗灯珠，表达实际安装关系。
  - 新增 wide/core 两层向上扩散光场，以 blur + radial/linear gradient 模拟灯光映射至桌后表面的漫反射。
  - 开启时灯珠显示彩色跑马，反射场为左侧冷蓝、中部青色、右侧低饱和暖光，并缓慢横向漂移。
  - 关闭时实体灯带仍可见，灯珠为暗灰色且无漫反射。
  - 支持 `prefers-reduced-motion`，系统减少动画时停止漂移动画。
- 修改 `src/views/labViews/page-lab.vue`：
  - 撤销灯带与手控器叠放的 `handset-stage`。
  - 恢复四层独立结构：电动桌后置灯带 / 手控器 / 按键 / 时间流速。
