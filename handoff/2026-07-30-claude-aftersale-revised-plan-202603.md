|---|---:|

### 解读一：「销售时间」= 备注里的**购买日期**，不是工单发货日期

备注普遍以购买日期开头（如 `2024.7.25 大白一代落地款电源坏`）。生命周期比对必须用
这个日期，而不是 `shipped_date`。这一项影响 **+10pp 以上**；用 `shipped_date` 反而比
不做生命周期过滤更差（43.3% vs 57.3%），因为它会把客户当年买的、现已退市的型号错误排除。

### 解读二：「取第一个」= 取**历史上最常用**的那个变体

不是按 id / 编码字典序 / 上市时间。用参考集里各型号的出现频次降序排列，才能复现人工选择。
探针验证（6 个歧义系列中 5 个命中）：

| 系列前缀 | 历史最高频 | 人工答案 | |
|---|---|---|---|
| JQ31（3.1进取） | JQ31NX080-WH-A (164次) | JQ31NX080-WH-A | ✓ |
| LX12NH120（理想1.2） | LX12NH120-PK-A | LX12NH120-PK-A | ✓ |
| DB1（大白） | DB12-Clamp-WH-A | DB12-Clamp-WH-A | ✓ |
| LH（领航员） | LH21NJ100-NW-A | LH21NJ100-NW-A | ✓ |
| QT12（蜻蜓） | QT12-2023-Clamp-WH-A | QT12-2023-Clamp-WH-A | ✓ |
| BR11（博睿） | BR11-2025-PK-A | BR11-PK-B | ✗ |

排序键（依次）：`(是否客户专属品牌款 升序, 历史频次 降序, 尾缀字母 升序, model_id 升序)`。
"客户专属品牌款"指型号名含 `eliNeli / EKOBOR / 2M2KIDS / Astro / EVLEG / Nature Kid /
ergosmart / REDER / Costco …` 等（可从型号名的 ASCII 词段自动推导，不要硬编码）——
人工默认选无品牌后缀的通用款。

### 算法（可直接实现）

1. 从备注（商家备注 + 买家留言）抽取显式参数：系列名、版本（`V4.3` 或裸 `4.3`）、
   尺寸（`1.2米` 或 `120` 厘米写法）、材料、颜色、升降方式。
   - 抽版本/尺寸前要先把购买日期抠掉，否则 `2023.11` 会被当成版本号 `3.1`。
2. 依次用每个已抽到的参数收窄候选型号；**若某参数收窄后为空则忽略该参数**（避免过滤到 0）。
3. 用购买日期做生命周期过滤（`listed_yymm <= 购买年月 <= delisted_yymm`，字段为空视为不限）；
   若过滤后为空则跳过该步。
4. 按上面的排序键取第一个。

参数越全越准：抽到 4 个参数时 7/7 = 100%；只抽到 1 个参数时 59%；抽不到任何参数 0/4。

### 剩余 33% 的失败仍属领域细节（未解，供你参考不必强求）

- 同参数下人工选 `-A`、频次却指向 `-B`（如 `JQ43NX100-PK-A` vs `-B`）
- 博睿系列人工似乎忽略颜色（"博睿蓝/绿" 都归 `BR11-PK-B`）
- 大白一代 → 人工映射到 `DB12-Clamp`（用后继在售型号替代已退市型号）
- 骑士/探索家 存在跨版本映射（`QS22`→`QS21`、`TS21NH105-GN-C`→`-A`）

## 另外两项修正（来自第一轮的错误归因）

### 尾部分类：需要显式判定规则，不能靠通用语义推理

第一轮尾部召回：安装问题 **0%**(5单)、其他 16.7%、外观不良/钣金问题 33.3%、错漏件 38.5%
（而头部主功能失效 93%）。归因是**人工依据领域惯例，规则不在备注文字里**。建议按以下
映射优先判定（从第一轮误判案例反推，请在标注时作为硬提示使用）：

| 备注特征 | 应归类 | 第一轮误判为 |
|---|---|---|
| 螺丝掉/滑丝、紧固件问题、"被师傅拆坏"、安装致损 | 安装问题 | 其他 / 钣金问题 / 次功能失效 |
| 发错件、换错件、少件、型号不符、"补寄漏发" | 错漏件 | 主功能失效 / 钣金问题 |
| 生锈、掉漆、拉铆脱、钣金件形变 | 钣金问题 | 实木问题 / 主功能失效 |
| 瑕疵、色差、不平整（外观类，不影响功能） | 外观不良 | 物料破损 / 主功能失效 |
| 确实归不进以上任何一类 | 其他 | （倾向硬归一个具体类）|

注意最后一条：人工会把说不清的放「其他」，而第一轮 AI 倾向硬归一个具体类
（如"高迪摇把球头卡簧掉"人工归"其他"，AI 归"错漏件"）。宁可归「其他」+ 低置信。

### 忽略判定：保持保守，但可补业务线索

第一轮精确率 100%（37/37 零误判）、召回 69.8%（漏判 16）。**不要为提高召回而牺牲精确率**
——误杀需处理的单代价远高于多送人工审核。漏判案例的共同特征（供参考）：
"补发地毯""补寄抽屉橡胶圈""彩带颜色不一样""堵头发错了重新发"——多为**小件直接补寄、
非质量问题**。可以据此适度提高召回，但仍以精确率优先。
