# 手控器桌高长按操作交接

日期：2026-08-04  
执行方：Codex  
接收方：Claude Code（审核与部署）

## 完成内容

- 主页桌高上、下键支持鼠标、触控和键盘长按。
- 升降以 38 mm/s 为基准速度，并按当前时间倍率加速模拟，范围限制为 650–1200 mm。
- 内部保留毫米精度，屏幕以整数厘米显示。
- 按住期间左侧卡片仅显示非方向性的“长按中”反馈，避免把关键信息放在会被手指遮挡的位置。
- 实时仪表突出方向动画和放大的当前高度，不显示速度或完整行程范围。
- 达到上下极限后显示“已到最高点/已到最低点”；只要仍在按住，极限界面保持不退出，松开后才恢复主页。
- 极限提示已从仪表内的小标签改为屏幕内容层上的独立大卡片，绝对定位叠加，不会推动桌高数字改变位置。
- 松开、取消指针、失去捕获、息屏或组件卸载均立即停止。
- 升降期间自动设置 `motionMode = lift`，停止后回到 `idle`，供遇阻逻辑判断。
- 建立 `light | dark` 屏幕主题状态和两套 CSS 变量；默认白色，后续设置页可直接调用切换接口。
